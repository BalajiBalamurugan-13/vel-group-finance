# Versioning Strategy

The project follows Semantic Versioning.

Format

MAJOR.MINOR.PATCH

Example

v1.0.0

Meaning

MAJOR

Breaking architectural or business changes.

MINOR

New features or major enhancements.

PATCH

Bug fixes, documentation updates, and minor improvements.
