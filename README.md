# 📖 Overview

VEL Finance - Group Finance is a modern financial management platform built to digitize and simplify group-based lending operations.

The application replaces manual bookkeeping with a scalable, enterprise-ready solution that manages groups, members, loan disbursements, weekly collections, outstanding balances, reports, and business analytics.

Although developed under the **VEL Finance** brand, this application is completely independent from the existing **VEL Finance Daily Collection** system.

---

# 🎯 Project Vision

Build a professional financial platform that enables business owners to manage group finance operations efficiently while providing a scalable foundation for future customer-facing services.

Future versions will support:
